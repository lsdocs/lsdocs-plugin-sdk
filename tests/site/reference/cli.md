# CLI reference

## Commands

lsdocs build
: Builds the site.

lsdocs init
: Starts a new site.

### `lsdocs build`

Builds the site. Use `--trace-rpc` to see every plugin message.

### `lsdocs init`

Creates `lsdocs.toml` and `docs/index.md`.
